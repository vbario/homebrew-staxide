# homebrew-staxide

Homebrew tap for [STAX IDE](https://staxide.com/).

## Install

```sh
brew tap vbario/staxide
brew install --cask staxide
```

Or one-shot:

```sh
brew install --cask vbario/staxide/staxide
```

## Update

```sh
brew update
brew upgrade --cask staxide
```

## Uninstall

```sh
brew uninstall --cask staxide        # removes the app
brew uninstall --cask --zap staxide  # also wipes ~/.termgrid + prefs
```
